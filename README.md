# PulseChronicle — Modern Tech & Culture Blog

A responsive dark-themed blog and news website built with pure HTML, CSS, and JavaScript.

## Features
- Responsive dark UI with featured hero report and live breaking-news ticker
- Instant search, category filtering, and sorting (`Latest First`, `Most Liked`, `Quick Reads`)
- Interactive article reader modal with reading progress bar
- Likes, bookmarks, and **Publish Story** modal persisted via `localStorage`
- Zero build step required — ready for Cloudflare Pages, GitHub Pages, or any static host
